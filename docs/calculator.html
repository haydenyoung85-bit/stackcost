How this is calculated

Executions = workflows × runs per month (30-day month). n8n Cloud counts one execution per full workflow run regardless of steps. VPS RAM guide: 2 GB up to ~20k executions/mo, 4 GB up to ~200k, 8 GB beyond — a rule of thumb, not a benchmark. VPS price uses the renewal price of verified USD plans (VPS/managed, PaaS excluded because it is usage-billed). Self-hosted n8n Community Edition has no execution limit.

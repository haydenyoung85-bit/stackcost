About StackCost

StackCost is built by Hayden Young to answer one question honestly: what does self-hosting n8n actually cost after the intro deal ends?

Method

  • Prices come only from providers’ public pages or public APIs, with the source URL and date checked.
  • Renewal price is shown first. If we can’t verify a number, we leave it blank and mark it unverified.
  • A script re-checks every source weekly and flags changes for review.

Last full check: 2026-10-22. Raw data: hosts.json.

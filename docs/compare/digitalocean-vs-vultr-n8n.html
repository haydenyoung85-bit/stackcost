Verdict

Vultr. 2 GB: $10 vs $12, 4 GB: $20 vs $24, 8 GB: $40 vs $48 per month (Vultr vs DigitalOcean, checked 2026-11-09). Both bill hourly with no intro price, so what you see is what you keep paying.

  • Pick Vultr for the lower price per GB.
  • Pick DigitalOcean if you value its documentation and tutorials, which cover n8n and Docker well.

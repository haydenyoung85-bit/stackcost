Can n8n run on 2 GB RAM?

Short answer: yes, for small setups. for light use: n8n itself idles at a few hundred MB. With SQLite and a handful of workflows 2 GB is workable; add Postgres, large binary data or many concurrent executions and 4 GB is safer. Add swap as a buffer.

  • Fine: personal automations, webhooks, a few scheduled jobs, SQLite.
  • Tight: Postgres + n8n + reverse proxy on one box, AI agent workflows with big payloads.
  • Upgrade when: you see OOM kills or executions above ~20k/month.
